# To-Do List

A clean, responsive To-Do List web app built with **HTML, CSS, and vanilla JavaScript**.

## Features

- Add tasks using the button or Enter key
- Mark tasks as completed or active
- Filter tasks by All, Active, and Completed
- Delete individual tasks
- Clear all completed tasks
- Automatically save tasks in browser `localStorage`
- Responsive layout for desktop and mobile
- Accessible labels and status announcements

## Run the project

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add your first task.

No package installation or build step is required.

## Project files

```text
todo-list/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Data storage

Tasks are stored locally in the current browser. They are not uploaded to a server. Clearing browser site data may remove saved tasks.

## GitHub upload

1. Create a repository named `todo-list` on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Commit the files.
4. To publish it as a website, open the repository's **Settings → Pages**, select the main branch and root folder, then save.
